## Description 

Working on this project helped me understand how to build a full web application using Vue.js and external APIs. I learned how to fetch and manage data, create reusable components, and troubleshoot deployment issues with GitHub Pages. The most challenging part was debugging errors during deployment, especially when the app showed a blank screen. Overall, this project gave me stress but also improved my problem solving skills and gave me more confidence in developing interactive and responsive web applications.
